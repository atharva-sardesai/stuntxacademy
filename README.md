# StuntX Academy Website (v1)

High-impact single-page landing site for StuntX Academy (Pune), built with Next.js App Router + TypeScript + Tailwind.

## Setup
```bash
pnpm install
pnpm dev
```

## Folder Structure
- `app/`: routes, layout, metadata, sitemap, robots.
- `components/sections`: page section components.
- `components/shared`: reusable visual helpers.
- `components/ui`: shadcn-style primitives.
- `lib/constants.ts`: editable content data.
